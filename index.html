Install on iPhone

Open this site in Safari, then tap Share → Add to Home Screen → Add. Enable Open as Web App if shown. Open the new Home Screen icon while online and wait for “Saved for offline use”. Import your private medicine data inside the Home Screen app. Then close it, turn on Airplane Mode, and reopen it to test lookup.

Your selected PDF is saved privately on this device for source-page links. Clearing website data or device storage cleanup can remove the app and imported data. Keep a backup of your private data file so you can import it again.
